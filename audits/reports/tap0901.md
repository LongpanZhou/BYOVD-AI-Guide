## Entry surface

- WDM NDIS miniport with a **per-adapter control device** registered via `NdisRegisterDeviceEx` (`FUN_00012230`): name `\Device\<NetCfgInstanceId>.tap` (strings `0x14940`, `0x14960`) and link `\DosDevices\Global\<NetCfgInstanceId>.tap` (`0x14970`).
- Device object flags patched after registration (`0x00012440`–`0x00012455`): `DO_BUFFERED_IO` bit cleared (`& 0xfffffffb`), `DO_DIRECT_IO` set (`| 0x10`) — MJ_READ/MJ_WRITE run as **direct IO** on the IRP's MDL.
- Dispatch (`FUN_00012230` table): MJ_CREATE `FUN_0001802c`, MJ_CLOSE `FUN_00018670`, cleanup `FUN_000186e0`, MJ_READ `FUN_00018740` (rxpath.c), MJ_WRITE `FUN_00018a30` (txpath.c), MJ_DEVICE_CONTROL `FUN_000180ec` (device.c).
- **DACL gate (decoded from assembly `0x000123D9`–`0x00012436`):**
  - `SecurityDescriptor = NULL` when the `AllowNonAdmin` value does **not** exist in the adapter's registry key → OS default device security (admin-gated).
  - When `AllowNonAdmin` value exists (set by an admin), the driver applies `UNICODE_STRING{len=0x7E, buf=0x153E0}` = `D:P(A;;GA;;;SY)(A;;GRGWGX;;;BA)(A;;GRGWGX;;;WD)(A;;GRGWGX;;;RC)` — **Everyone GRGWGX**. Four SDDL constants exist at `0x151C8/0x15210/0x15260/0x152D0` (admin-only / admin-RX / Everyone-GR variants); the decisive pointer table at `0x15460` selects the Everyone-full string. Only an administrator can create that registry value, so the permissive mode is admin-initiated.
- No `Se*` imports; no privilege checks in any handler.

## Memory-write analysis

**Control plane (`MJ_DEVICE_CONTROL` = `FUN_000180ec`):** codes `0x220004`–`0x220028` (device `0x22` FILE_DEVICE_UNKNOWN, Fn 1–0xA, **all METHOD_BUFFERED + FILE_ANY_ACCESS**), buffers via `Irp->SystemBuffer` (`Irp+0x18`). Every handler checks `InputBufferLength`/`OutputBufferLength` before writing:

| Code | Fn | Check | Action |
|---|---|---|---|
| `0x220004` | 1 | out ≥ 6 | 6 B MAC copy-out from adapter+0xeb |
| `0x220008` | 2 | out ≥ 12 | fixed 12 B version out |
| `0x22000C` | 3 | out ≥ 4 | 4 B MTU out |
| `0x220010` | 4 | — | bounded `_vsnprintf` into SystemBuffer (size = outLen) |
| `0x220014` | 5 | in ≥ 8 | fixed-field MAC/MTU config store |
| `0x220018` | 6 | in ≥ 4 | 1-byte media status via `FUN_00012060` |
| `0x22001C` | 7 | in ≥ 0x10 | fixed-field store at adapter+0x324 |
| `0x220024` | 9 | **in < 0x101** | `memcpy(adapter+0x33c, in, inLen)` into exactly-0x100-byte field (0x33c→0x43c); count stored at +0x43c |
| `0x220028` | 0xA | in ≥ 0xC | fixed fields + `(a & b) == a` mask check |
| default | | | `0xC0000010` |

The single `memcpy` (`0x220024`) is clamped to `< 0x101` and the destination field is exactly `0x100` bytes — bounded. ✓

**Data plane (direct IO):**
- `MJ_WRITE` (`FUN_00018a30`, txpath.c:0x45d): maps `Irp->MdlAddress` — `MmMapLockedPagesSpecifyCache(Mdl, KernelMode, …)` only when `(Mdl->MdlFlags & 5) == 0`, else uses `Mdl->MappedSystemVa`. No in-driver `MmProbeAndLockPages` call, **but the MDL arrives from the I/O manager (direct-IO path), which probes+locks the pages before dispatch**; user mode cannot forge an unlocked MDL through `NtWriteFile`/`NtDeviceIoControlFile`. The transfer length comes from the MDL's own `ByteCount` (+0x28) and the SL Parameters — mutually consistent.
- `MJ_READ` (`FUN_00018740`, rxpath.c): same idiom; builds a NetBufferList over the mapped view with length = `Mdl->ByteCount` (`uVar12`), optionally prepending a 14-byte kernel header via `NdisAllocateMdl` (`Mxtk`-tagged pool `lVar3+0x306/0x314` — fixed kernel context fields, not user data). `NdisMIndicateReceiveNetBufferLists` consumes it; the IRP stays pending in the CSQ (`IoCsqInsertIrp`, `lVar1+0x240`) until completion — the mapped view lifetime is bounded by the IRP's own MDL lifetime.

**Not found:** no `MmMapIoSpace`, `MmGetPhysicalAddress`, `ZwOpenSection`, `MmCopyMemory`, `Se*` imports; no METHOD_NEITHER codes; no MSR/GDT/IDT touch; no unchecked fills; no user-length-driven kernel-buffer writes.

## Verdict + VM confirmation plan

**NO-WRITE.** The TAP control plane is fully bounds-checked, and the direct-IO data plane maps only I/O-manager-locked caller pages. The only exposure widening (Everyone GRGWGX via `AllowNonAdmin`) requires an administrator-set registry value and grants no memory-write primitive even then — worst-case effect is control-plane misuse (media status, MTU, injected frames), which is out of scope for round 2.

VM plan (orchestrator-owned, non-destructive): enumerate `\\.\*.tap` devices; open under a restricted token with and without `AllowNonAdmin` present to record the DACL behavior; issue `0x220004` (GET_MAC) and a small pending MJ_READ to confirm the rxpath CSQ path; no corruption test warranted by static evidence.
