# audits/reports/

One canonical report per driver, flat, named `<driver>.md`. Variants may add `.admin.static`,
`.dynamic`, or `.independent.static`, but must name the canonical file.

Use the skeleton in [`../scope/STATIC_ANALYSIS_AGENT_PROMPT.md`](../scope/STATIC_ANALYSIS_AGENT_PROMPT.md).
Every report states **Reach**, **Setup**, **Write quality**, and **Verdict**.
